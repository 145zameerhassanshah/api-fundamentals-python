# API Fundamentals with Python

A practical project demonstrating HTTP API communication using Python Requests and Thunder Client.

## Objective

Understand how clients and servers communicate through HTTP APIs and practice GET and POST requests, headers, status codes, query parameters, JSON request/response bodies, and basic error handling.

## Concepts Covered

- API fundamentals
- Client-server communication
- HTTP request/response lifecycle
- GET requests
- POST requests
- Query parameters
- Request and response headers
- JSON payloads
- HTTP status codes
- Timeouts
- Exception handling
- API testing with Thunder Client
- Basic curl usage
